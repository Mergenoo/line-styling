# LINE Styling

Static website for LINE Styling, a bespoke tailoring house in Ulaanbaatar. No build step.

- `index.html` is the whole site (styles and script are inline).
- Pictures in `assets/` are openly licensed archive images, credited in the footer (see `assets/credits.json`).
- The earlier home page is in git history (commit "Add LINE Styling website").

Deploy on Vercel as a static project: framework preset "Other", no build command, output directory = root.
