# LINE Styling

Static website for LINE Styling, a bespoke tailoring house in Ulaanbaatar. No build step.

- `index.html` is the home page.
- `atelier.html` is an alternative, Savile Row-style page (served at `/atelier`).
- Pictures in `assets/` are openly licensed archive images, credited in each page's footer (see `assets/credits.json`).

Deploy on Vercel as a static project: framework preset "Other", no build command, output directory = root.
